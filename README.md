# CinePick

- Esse projeto foi criado com o intuito de facilitar suas escolhas para o próximo filme com sua(seu) amada(sua), no caso com minha amada que me motivou a fazer esse.
- A ideia foi dada por causa de um projeto antigo de filmes que ela achou legal e queria de volta, então decidi refazer ele me desafiando com uma biblioteca nova para que eu pudesse aprender mais enquanto faço

- Aplicação feita pensando no mobile.

- Aplicação sem muito segredo:
** npm i
** npm run dev
